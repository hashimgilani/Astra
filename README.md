# Astra — AI Powered Ecommerce Analytics App

Astra is a Streamlit based analytics app that helps ecommerce store owners analyze sales data, clean datasets, and generate clear visual insights.

## Live App
Open here:
https://astraio.streamlit.app/

## What It Does

- Upload CSV or Excel ecommerce sales data
- Automatically clean messy or inconsistent columns
- Generate interactive revenue and product performance charts
- Identify trends and key performance metrics
- Provide simple AI driven insights

## Why I Built It

I built Astra to simulate how ecommerce teams analyze store performance. The goal was to combine data cleaning, visualization, and insight generation into one simple and user friendly application.

## Tech Stack

- Python
- Streamlit
- Pandas
- Data visualization libraries
